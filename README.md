## Projetos em Destaque

🔹 **FMS** → [Live Demo](https://franchiseos-plum.vercel.app/) | [Repositório](https://github.com/guilhermegodoydev/franchiseos)

Sistema web de gerenciamento de franquias, em evolução. Hoje cobre CRUD de unidades com autenticação JWT, controle de acesso por role e isolamento de dados por sede.
O projeto nasceu para praticar um fluxo completo de ponta a ponta, com autenticação implementada manualmente (JWT, claims e roles) em vez de solução pronta, API em .NET e frontend em Next.js com mutações executadas no servidor.
Próximos passos: gestão de royalties, dashboard, relatórios e acesso para franqueados.

**Stack: Next.js • .NET • Entity Framework Core • PostgreSQL • shadcn/ui**

🔹 **Snapport** → [Documentação](https://guilhermegodoydev.github.io/snapport) | [Repositório](https://github.com/guilhermegodoydev/snapport)

Utiliza GitHub API para gerar automaticamente a interface baseada em repositórios e topics.
A ideia do projeto surgiu da necessidade de eliminar manutenção manual de portfólios, sincronizando automaticamente os projetos com base em dados do GitHub.
A lib fornece uma forma simples de renderizar e organizar projetos diretamente no DOM, com suporte a filtros, busca e personalização via configuração.

**Stack: TypeScript • GitHub API**

🔹 **Nexapulse** → [Live Demo](https://nexapulse.netlify.app/) | [Repositório](https://github.com/guilhermegodoydev/nexapulse)

CRM B2B desenvolvido como uma reconstrução completa de uma versão anterior, com foco em arquitetura escalável, consistência de dados e definição clara de MVP.
O projeto foi reestruturado utilizando Feature-Sliced Design (FSD), separando responsabilidades por domínio para melhorar manutenibilidade e escalabilidade da aplicação.
A camada de dados foi migrada para Supabase, utilizando PostgreSQL e políticas de segurança (RLS), junto com React Query para gerenciamento de estado assíncrono e cache inteligente.

**Stack: React • Vite • TypeScript • Supabase • React Query • Zod**
